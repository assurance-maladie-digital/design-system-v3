<div className="header">
  <h1>Correspondances couleurs</h1>
  <p>Aide à la migration&nbsp;: correspondance entre les anciens tokens sémantiques et les nouveaux tokens unifiés.</p>
</div>

Ces correspondances sont **vérifiées contre le code dans les trois thèmes** (cnam, pa, amelipro)&nbsp;: seules sont listées celles dont la **valeur est préservée à l'identique** dans chaque thème (ancien `*Semantic.ts` → nouveau `*LightTheme.ts`). Les nouveaux tokens sont exposés comme couleurs de thème (`var(--v-theme-<token>)`, classes `text-<token>`, `bg-<token>`…).

> **Success (`text` / `border` / `icon`)** — ces tokens correspondent à `onSuccessVariant`.

> **Premier plan feedback** — `onInfoVariant`, `onSuccessVariant`, `onWarningVariant`, `onErrorVariant` sont les couleurs de **texte / icône / bordure** à poser sur les fonds `infoVariant` / `successVariant` / `warningVariant` / `errorVariant`.
>
> - `onSuccessVariant` et `onWarningVariant` reprennent la valeur des anciens `text/border.success` et `.warning`.
> - `onInfoVariant` et `onErrorVariant` sont des nuances **plus foncées introduites par la refonte**, **sans équivalent ancien** (l'ancien texte info/error utilisait la couleur principale → voir `info` / `error`).
