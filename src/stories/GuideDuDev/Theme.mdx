Le thème par défaut du Starter kit est celui de la Cnam par défaut.
Si votre projet dépend du Portail Agent ou d'Amelipro, appliquez le thème correspondant à votre ligne de fabrication.

La configuration de Vuetify fournie par Synapse contient les trois thèmes : voir [Configurer Vuetify](/docs/guide-du-dev-démarrage-installation--docs#configurer-vuetify).

## Appliquer le thème dans le composant racine

<Source dark code={`
<template>
  <VApp theme="pa">
    <!-- votre application -->
  </VApp>
</template>
`}
/>

## Appliquer le thème à toute l'application

Pour appliquer le thème sans modifier le composant racine, passez-le en `defaultTheme` dans la configuration Vuetify&nbsp;:

<Source dark language="ts" code={`
// src/plugins/vuetify.ts
import { createVuetify } from 'vuetify'
import { createVuetifyOptions } from '@cnamts/synapse/vuetifyOptions'

const options = createVuetifyOptions()

export const vuetify = createVuetify({
  ...options,
  theme: {
    ...options.theme,
    defaultTheme: 'pa',
  },
})
`}
/>

Après avoir modifié le thème, relancez le serveur de développement :

<Source dark code={`
pnpm dev
`}
/>
