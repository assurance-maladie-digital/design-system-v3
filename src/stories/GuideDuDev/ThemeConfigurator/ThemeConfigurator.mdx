Un projet peut ajuster un nombre **limité** de réglages de Synapse : la marque par défaut, l'anneau de focus clavier et le style des champs de formulaire.
Tout le reste est verrouillé, pour garder un rendu cohérent entre les projets. Chaque réglage est validé : une valeur hors bornes ou non accessible est refusée et remplacée par sa valeur par défaut.

## Configurateur

Composez votre configuration, vérifiez le rendu et la validation, puis copiez le fichier généré.

<Story of={ThemeConfiguratorStories.Configurator} />

## Utilisation

Passez la configuration à `createVuetifyOptions` (ou à `createVuetifyInstance`, qui accepte le même objet). Sans argument, le rendu Synapse par défaut est conservé à l'identique.

<Source dark language="ts" code={`
import { createVuetify } from 'vuetify'
import { createVuetifyOptions } from '@cnamts/synapse/vuetifyOptions'
import themeConfig from './synapse.theme.json'

app.use(createVuetify(createVuetifyOptions(themeConfig)))
`} />

### Champs concernés par `fields`

`fields` ne s'applique que si le projet le renseigne. Il concerne les champs Vuetify (`VTextField`, `VTextarea`, `VSelect`, `VAutocomplete`, `VCombobox`, `VFileInput`) et les champs Synapse : `SyTextField`, `SyTextArea`, `SySelect`, `SyAutocomplete`, `PasswordField`, `NirField`, `PhoneField`, `LunarCalendar`, `SearchListField`, `DatePicker` et `PeriodField`.

Une prop passée explicitement sur un champ (par exemple `variant-style`, `outlined`, `is-outlined` ou `density`) reste toujours prioritaire sur la configuration.

## Valider la configuration en CI

`checkThemeConfig` vérifie la configuration avec les couleurs réelles de la marque choisie :

<Source dark language="ts" code={`
import { checkThemeConfig } from '@cnamts/synapse/vuetifyOptions'
import themeConfig from './synapse.theme.json'

const { valid, issues } = checkThemeConfig(themeConfig)
if (!valid) {
  console.error(issues)
  process.exit(1)
}
`} />
