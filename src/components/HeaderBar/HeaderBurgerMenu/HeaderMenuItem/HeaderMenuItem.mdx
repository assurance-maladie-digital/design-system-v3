Le composant `HeaderMenuItem` est un composant de menu qui permet de wrapper un lien de navigation. Cela peut être un lien `a`, `router-link` ou `nuxt-link`.
Le composant rend un `li` par défaut. Dans le slot principal de `HeaderBurgerMenu`, la liste `ul` est ajoutée automatiquement : utilisez directement `HeaderMenuItem` pour une liste simple. Pour regrouper les items, placez-les dans le slot principal d'un `HeaderMenuSection`, qui fournit sa propre liste `ul`. Si vous utilisez `HeaderMenuItem` ailleurs, assurez-vous qu'il est contenu dans un `ul`.

<Source
  dark
  code={`
<ul>
	<HeaderMenuItem>
		<a href="/">Home</a>
	</HeaderMenuItem>
	<HeaderMenuItem>
		<a href="/about">About</a>
	</HeaderMenuItem>
</ul>

<ul>
	<HeaderMenuSection title="Navigation">
		<HeaderMenuItem>
			<a href="/">Home</a>
		</HeaderMenuItem>
		<HeaderMenuItem>
			<a href="/about">About</a>
		</HeaderMenuItem>
		<HeaderMenuItem>
			<RouterLink to="/services">Services</RouterLink>
		</HeaderMenuItem>
		<HeaderMenuItem>
			<NuxtLink to="/contact">Contact</NuxtLink>
		</HeaderMenuItem>
	</HeaderMenuSection>
</ul>
`}
/>

Pour plus de détails sur le contexte d'utilisation de ce composant, veuillez consulter le composant `HeaderBurgerMenu`.
