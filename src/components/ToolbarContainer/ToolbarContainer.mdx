Le composant `ToolbarContainer` est un conteneur pour les barres d'outils, il permet de regrouper plusieurs boutons d'actions sous une simple action 'tab'. Les boutons sont alors accessibles au clavier via l'usage des flèches directionnelles.

Ce composant intègre [le pattern `toolbar` tel que défini par le W3C](https://www.w3.org/WAI/ARIA/apg/patterns/toolbar/).
