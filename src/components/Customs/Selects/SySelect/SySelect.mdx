# API

<Controls of={SySelectStories.Default} />

<p>
	<b>Sécurité :</b> avec la prop <code>allowHtml</code>, le texte des options est filtré avant d'être affiché.
	Seules les balises <code>abbr</code> (avec son attribut <code>title</code>), <code>span</code> (avec son attribut <code>class</code>), <code>b</code>, <code>strong</code>, <code>em</code> et <code>i</code> sont conservées, sans aucun autre attribut (<code>style</code> notamment est retiré).
	Les autres balises sont retirées en gardant leur texte ; <code>script</code>, <code>style</code>, <code>iframe</code>, etc. sont supprimées avec leur contenu.
</p>

# Exemple d'utilisation

<Source dark code={`
<script setup lang="ts">
	import { ref } from 'vue'
	import { SySelect } from '@cnamts/synapse'

	const selectedValue = ref(undefined)

	const items = [
		{ text: 'Option 1', value: '1' },
		{ text: 'Option 2', value: '2' },
	]
</script>

<template>
	<main class="ma-12">
		SelectedValue: {{ selectedValue }}
		<div class="d-flex flex-wrap align-center">
			<SySelect
				v-model="selectedValue"
				:items="items"
				text-key="text"
				required
			/>
		</div>
	</main>
</template>
`} />
