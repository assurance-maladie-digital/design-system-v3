# UserMenuBtn — amélioration de la documentation `WithPsInfo`

Le code affiché par la story `WithPsInfo` correspond désormais exactement au rendu présenté dans Storybook.

La documentation illustre notamment :

- le nom complet avec la prop `full-name`;
- les informations professionnelles avec la prop `additional-information`;
- les informations détaillées dans le slot par défaut;
- les actions `Mon compte` et `Déconnexion`;
- les données de RPPS, ADELI, adresse électronique et de dernière connexion.

Il s’agit d’une correction de documentation, sans modification de l'API ni du comportement de `UserMenuBtn`.
