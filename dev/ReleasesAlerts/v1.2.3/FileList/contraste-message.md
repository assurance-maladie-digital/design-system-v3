# FileList — changement visuel du message d’information

Le texte « Document facultatif » et les messages personnalisés de `FileList` utilisent désormais la couleur `on-surface` du thème. Ils utilisaient auparavant `on-surface-variant`, qui rendait le texte difficile à lire sur fond clair.

## Conduite à tenir

Aucune action nécessaire. La couleur s’applique automatiquement.
