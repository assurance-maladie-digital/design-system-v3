# SyBtnMenu — affichage multiligne des informations

Les informations secondaires affichées dans le bouton ainsi que les intitulés des éléments du menu peuvent désormais s'afficher sur plusieurs lignes. Les retours à la ligne présents dans les informations secondaires sont également respectés.

Il s’agit d’une amélioration visuelle sans modification de l'API.

## Conduite à tenir

Aucune modification du code consommateur n'est nécessaire. Vous pouvez fournir des retours à la ligne dans `secondaryInfo` pour présenter les informations secondaires sur plusieurs lignes.
