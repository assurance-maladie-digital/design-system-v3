# DatePicker — description accessible des plages de dates

En mode `displayRange`, la description associée au champ via `aria-describedby` indique l’ordre de saisie (date de début, puis date de fin) et le format attendu pour chaque date. Elle indiquait auparavant uniquement le format d’une date.

## Conduite à tenir

- Si vos tests vérifient le texte de la description accessible en mode plage, adaptez-les à la nouvelle consigne.
