# SyTextField — prop `direction` dépréciée (non cassant)

La prop `direction` de `SyTextField` n'a jamais eu d'effet : `VTextField` ne la prend pas en charge, et la valeur finissait en attribut HTML invalide `direction="horizontal"` sur l'`<input>` (RGAA 8.2, code source valide). L'attribut n'est plus rendu. Tous les composants construits sur `SyTextField` sont concernés (`PhoneField`, `NirField`, `PasswordField`, `DatePicker`, etc.).

La prop reste acceptée pour ne pas casser les projets qui la passent, mais elle est marquée `@deprecated` et sera retirée dans une version majeure.

## Conduite à tenir

Aucune pour le rendu, qui ne change pas. Vous pouvez retirer `direction` de vos usages de `SyTextField`. Si vos tests ou snapshots attendaient l'attribut `direction` sur l'`<input>`, mettez-les à jour.
