# FilePreview

Critères ciblés : RGAA 1.1, 1.2, 7.1 et 11.1.

Les tests vérifient l’alternative textuelle d’une image. Pour les PDF rendus en canvas, le slot `alternative`, le lien de téléchargement de secours, le mode lecture seule et le suivi de consultation nécessitent des scénarios manuels et navigateur dédiés.
