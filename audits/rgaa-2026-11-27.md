## Non-conformité détectée

### [NC potentielle] 7.1 — Script compatible avec les technologies d’assistance

- **Élément concerné :** panneau `.sy-accordion-content`, lignes 178–185 de `Accordion.vue`.
- **Constat :** lorsqu’un panneau est fermé, il reste présent dans le DOM avec `role="region"`, tandis que le masquage est uniquement réalisé par `max-height: 0` et `overflow: hidden`. Aucun attribut `hidden` ou `aria-hidden="true"` n’est appliqué.
- **Risque :** le contenu fermé peut rester exposé dans l’arbre d’accessibilité malgré `aria-expanded="false"`, selon le navigateur et le lecteur d’écran.
- **Correction recommandée :** utiliser le mécanisme de masquage attendu par le pattern disclosure, par exemple `:hidden="!isItemOpen(item.id)"`, ou appliquer une stratégie équivalente validée avec les lecteurs d’écran. Préserver la transition visuelle avec une structure dédiée si nécessaire.
- **Priorité :** 🟠 Majeur.
- **Vérification complémentaire :** tester avec NVDA/Firefox ou VoiceOver/Safari après correction.

## Critères conformes

**1.2, 3.2, 3.3, 7.3, 8.2, 9.1, 10.1, 10.2, 10.3, 10.4, 10.5, 10.7, 10.11, 10.12, 12.8, 12.9.**

Éléments confirmés dans le code :

- `role="button"`, `aria-expanded`, `aria-controls` et `aria-disabled` sur chaque en-tête ;
- `role="region"` et `aria-labelledby` sur chaque panneau ;
- activation par clic, Entrée et Espace ;
- navigation par flèches, Home et End ;
- titres sémantiques configurables ;
- icône décorative rendue avec `SyIcon decorative` ;
- indicateur de focus visible via `:focus-visible` et le style DS ;
- absence de `tabindex` positif et possibilité de sortir du composant avec Tab.

## Critères non applicables

Les autres critères RGAA sont non applicables au composant isolé : cadres, multimédia, tableaux, liens, formulaires, limites de temps, documents bureautiques, orientation, gestes complexes, mouvement de l’appareil et navigation globale du site.

Cette conclusion ne dispense pas d’un audit de la page consommatrice : le niveau de titre fourni, les contrastes du thème personnalisé, les liens ou contrôles injectés dans les slots et la structure globale de la page doivent être vérifiés dans leur contexte réel.
