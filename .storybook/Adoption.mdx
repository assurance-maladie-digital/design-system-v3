## Comment ces données sont produites

- Source : `src/usage/usage.json`, généré par `scripts/usage-report.mjs`.
- Collecte : **analyse AST** des repos consommateurs, sur **GitHub et GitLab** (instance interne
  comprise). Chaque repo est cloné, puis ses fichiers `.vue`/`.ts`/`.tsx`/`.js`/`.jsx` sont parsés
  avec le compilateur TypeScript pour ne compter que les **imports réels** de `{usage.package}`
  (imports nommés et imports par défaut via sous-chemin).
- Repos analysés (par fournisseur) : liste explicite (`GITHUB_REPOS` / `GITLAB_PROJECTS`), sinon
  auto-découverte (`GITHUB_TOKEN` + `GITHUB_ORG` ; `GITLAB_TOKEN` + `GITLAB_GROUP` + `GITLAB_HOST`).
- Mise à jour : commande `pnpm usage:report` (manuelle) ou via le workflow planifié
  `.github/workflows/usage-report.yml` (hebdomadaire).
