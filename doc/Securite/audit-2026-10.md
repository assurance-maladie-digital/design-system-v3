# Audit de sécurité — octobre 2026

Audit réalisé sur la branche `chore/security-audit` (base `dev`, commit `9b8c8644c`).

## Périmètre

Analysés : code de la librairie (`src/components`, `src/composables`, `src/utils`), pages Storybook publiées sur Netlify, workflows GitHub Actions, dépendances (`pnpm audit`), secrets versionnés, contenu du paquet npm (champ `files`).

Hors périmètre :

- clickjacking sur des pages sans fonctionnalité sensible ou sans scénario ;
- CSRF sur des formulaires non authentifiés ou non sensibles ;
- injection CSV sans scénario réel ;
- usurpation de contenu et injection de texte sans vecteur d'attaque ni modification du HTML/CSS ;
- vulnérabilités limitées aux navigateurs non à jour (plus de 2 versions stables de retard) ;
- vulnérabilités nécessitant une interaction peu probable de l'utilisateur.

### 1. Injection de commande — `update-a11y-status.yml`

`${{ github.event.head_commit.message }}` était interpolé dans un script `run`. Le workflow se déclenche sur tout push.

**Scénario :** un contributeur externe place dans un message de commit de sa PR le marqueur `[update a11y report]` et une charge shell (`"; … ; echo "`). Lors d'un squash merge, ce message est repris par défaut dans le commit poussé sur `dev` et exécuté sur le runner. Via `GITHUB_ENV` / `GITHUB_PATH`, la charge peut détourner les étapes suivantes, exécutées après le checkout qui conserve le `GITHUB_TOKEN` (droits par défaut du dépôt, aucun bloc `permissions`).

**Correctif :** le message passe par une variable d'environnement (`env: COMMIT_MESSAGE`), affichée avec `printf`. Ajout de `permissions: contents: write`.

### 2. `SySelect` — `allowHtml`

`SySelect.vue` assigne `innerHTML` avec le texte des options lorsque `allowHtml` est actif. Une application consommatrice qui alimente les options avec des données utilisateur ou issues d'une API s'expose à une XSS stockée.

**Correctif appliqué :** avertissement explicite dans la description de la prop (`SySelect.stories.ts`) et dans `SySelect.mdx`.

**Recommandation :** déprécier `allowHtml` au profit d'un slot d'item, comme pour `renderHtmlValue` de `DataListItem`. Ce changement d'API publique est à arbitrer séparément.

### 3. Injection de commande — `update-visual-snapshots.yml`

`${{ github.event.inputs.spec }}` était interpolé dans un script `run`. Seuls les utilisateurs ayant les droits d'écriture peuvent déclencher le workflow.

**Correctif :** l'entrée passe par une variable d'environnement (`env: SPEC_FILTER`).

### 4. `v-html` dans Storybook

- `ComponentTrackingPage.vue` : les messages de commit étaient injectés tels quels. Le `v-html` est supprimé : le message est découpé en segments et rendu en texte, la référence de PR restant un lien.
- `Releases.stories.ts` : le markdown des releases, récupéré depuis l'API GitHub, était converti par `marked` sans filtrage. La sortie passe désormais par `sanitizeHtml` (liste blanche de balises et d'attributs, URL limitées à `http(s):`, `mailto:` et `#`). Les attributs `style` sont retirés : le texte des releases existantes est inchangé, seule une partie de leur mise en forme inline est perdue.

Tests ajoutés : `src/stories/Demarrer/SuiviDesComposants/tests/ComponentTrackingPage.spec.ts`, `src/stories/Demarrer/tests/sanitizeHtml.spec.ts`.

### 5. Dépendances

`pnpm audit --prod` : aucune vulnérabilité.

`pnpm audit` (dev) : l'override `handlebars` passe à `>=4.7.10` (3 alertes dont 2 critiques corrigées). Restent `braces` (via `semantic-release`) et `sprintf-js` (via `vite-plugin-dts`) : déni de service, sans version corrigée publiée, sur des outils qui ne traitent pas de données non fiables.

## Points vérifiés sans risque exploitable

- `href` / `window.location.href` sans contrôle du schéma `javascript:` (`HeaderToolbar`, `HorizontalNavbar`, etc.) : URL fournies par le développeur consommateur, sans vecteur réaliste.
- `target="_blank"` sans `rel` : `noopener` implicite dans les navigateurs à jour.
- `FilePreview` : les URL `blob:` ne sont utilisées que dans `<img>` (pas d'exécution de script SVG) et `<object type="application/pdf">`.
- `AmeliproIcon` : SVG issus d'un dictionnaire statique interne.
- `EcoGuideComponent`, `FauxPositifs` : `v-html` sur des données statiques ; la recherche ne fait que surligner du texte existant.
- `LocalStorageUtility` : exploitation impossible sans accès préalable à la même origine.
- `downloadFile`, `copyToClipboard` : sans risque.
- Aucun secret versionné ; le champ `files` de `package.json` exclut stories et tests du paquet publié.
